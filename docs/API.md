# API Mahir Excel

Basis: `/api`. Semua respons JSON.

- Sukses: `{ "data": ..., "meta"?: { "page", "pageSize", "total" } }`
- Galat: `{ "error": { "code", "message", "details"? } }`

Kode galat: `VALIDATION_ERROR` (400/413), `UNAUTHENTICATED` (401), `FORBIDDEN` (403), `CSRF_INVALID` (403), `NOT_FOUND` (404), `CONFLICT` (409), `RATE_LIMITED` (429), `INTERNAL_ERROR` (500), `SERVICE_UNAVAILABLE` (503, mis. database mati).

## Autentikasi

Sesi memakai JWT (HS256, 7 hari) di cookie **HttpOnly** `excellab_session` (`SameSite=Lax`, `Secure` di produksi). Tidak ada token di localStorage.

CSRF: cookie `excellab_csrf` (dapat dibaca JS). Setiap permintaan `POST/PUT/DELETE` dari pengguna yang sedang login harus menyertakan header `X-CSRF-Token` dengan nilai yang sama. Login dan registrasi dikecualikan. Token juga dikembalikan oleh `register`, `login`, dan `me` (`csrfToken`).

| Metode & path              | Auth | Keterangan                                                                                                                                                                                                                                                              |
| -------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /auth/register`      | -    | `{ email, password (8-72), displayName }` → 201 `{ user, csrfToken }`. Email ganda → 409. Dibatasi 10/15 menit/IP.                                                                                                                                                      |
| `POST /auth/login`         | -    | `{ email, password }` → `{ user, csrfToken }`. Salah → 401 dengan pesan generik. Dibatasi 20/15 menit/IP.                                                                                                                                                               |
| `POST /auth/logout`        | -    | Menghapus cookie.                                                                                                                                                                                                                                                       |
| `GET /auth/me`             | -    | `{ user: null }` untuk anonim (bukan 401).                                                                                                                                                                                                                              |
| `GET /auth/config`         | -    | `{ emailEnabled }`: apakah server dapat mengirim email.                                                                                                                                                                                                                 |
| `POST /auth/email/request` | -    | `{ email, purpose: 'login'                                                                                                                                                                                                                                              | 'reset' }`→ selalu`{ sent: true, cooldownSeconds: 60 }`(tidak membocorkan status akun). 503 bila email dimatikan. Admin tidak dapat memakai`login`; `reset` hanya untuk akun yang ada. Dibatasi 10/15 menit/IP; jeda 60 dtk per email. |
| `POST /auth/email/verify`  | -    | `{ email, purpose, code (6 angka), newPassword? (wajib untuk reset), displayName? }` → `{ user, csrfToken, isNew }` dan sesi. Kode 10 menit, sekali pakai, 5 percobaan. Login membuat akun baru (tanpa kata sandi) bila email belum terdaftar. Dibatasi 20/15 menit/IP. |
| `DELETE /auth/account`     | ya   | `{ password }`. Menghapus akun dan seluruh progres (cascade).                                                                                                                                                                                                           |

## Akses

Semua endpoint di bagian "Publik" di bawah ini yang menyajikan materi belajar (`/modules`, `/lessons`, `/exercises` termasuk submit dan reveal, `/shortcuts`, `/worksheets` termasuk unduhan, `/challenges`) **mewajibkan sesi login**; tanpa sesi responsnya 401. Yang tetap terbuka tanpa akun: `/health`, `/auth/*`, `/track`, `POST /placement`, `GET /share/:token`, dan `GET /certificates/:code`.

| Endpoint                                     | Auth  | Keterangan                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------- | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /public/overview`                       | -     | Angka asli kurikulum untuk beranda pengunjung: `counts` (modul, pelajaran, latihan, shortcut, worksheet, fungsi) dan daftar modul dengan jumlah pelajaran dan latihan. Tanpa isi pelajaran.                                                                                                                                                                                                                                                     |
| `GET /public/lessons`                        | -     | Daftar singkat pelajaran contoh (slug, judul, ringkasan, menit, modul). `GET /lessons/:slug` hanya terbuka tanpa login untuk slug di `PUBLIC_LESSON_SLUGS`; slug lain 401.                                                                                                                                                                                                                                                                      |
| `POST /auth/google`                          | -     | `{ credential }` ID token dari Google Sign-In. Server memverifikasi tanda tangan RS256, audience (Client ID), issuer, dan masa berlaku; `email_verified` wajib. Mengembalikan `{ user, csrfToken, isNew }` (201 untuk akun baru). Akun admin ditolak (403); email yang sudah tertaut ke akun Google lain ditolak (403). 503 bila `GOOGLE_CLIENT_ID` kosong.                                                                                     |
| `GET /auth/config`                           | -     | `{ emailEnabled, googleClientId, premium: { priceLabel, contactUrl } }`.                                                                                                                                                                                                                                                                                                                                                                        |

| `POST /sprint/start`                         | -     | Memulai ronde Sprint tanpa akun. Mengembalikan `{ token, durationMs, endsAtMs, serverNowMs, question }`; soal tanpa kunci jawaban. Dibatasi 40/15 menit/IP.                                                                                                                                                                                                                                                                                     |

Hari ini dihitung menurut WIB.                                                                                                                                                                                                                                                                                                                     |

Dibatasi 30/15 menit/IP; dikecualikan dari CSRF karena terbuka untuk anonim. |

## Progres (login)

Semua endpoint progres selalu memakai pengguna dari sesi; tidak ada parameter id pengguna (mencegah IDOR).

| Endpoint               | Keterangan                                                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /progress`        | `{ completedLessons[], exercises{slug:{completedAt,attempts,points}}, reviews{}, activeDays[], totalPoints, streak{current,longest} }`                                                                                                                              |
| `PUT /progress`        | `{ lessonSlug, completed }`, idempoten.                                                                                                                                                                                                                             |
| `POST /progress/sync`  | `{ snapshot: { completedLessons, exercises, reviews, activeDays } }`. Validasi slug, poin dari definisi server, tanggal dibatasi 400 hari ke belakang dan tidak di masa depan, idempoten. Respons `{ progress, imported:{lessons,exercises,pointsAdded,skipped} }`. |
| `GET /progress/review` | Latihan yang jawaban terakhirnya salah dan belum diselesaikan.                                                                                                                                                                                                      |

### Ulang terjadwal, berbagi, dan sertifikat

| Endpoint                            | Auth | Keterangan                                                                                                                           |
| ----------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `GET /progress/review-due`          | ya   | Latihan yang jatuh tempo diulang (kotak 0-5, interval 1/3/7/14/30 hari, zona WIB).                                                   |
| `GET /progress/share`               | ya   | `{ token \| null }`: status tautan berbagi.                                                                                          |
| `POST /progress/share`              | ya   | Membuat (atau memutar) token berbagi. `DELETE /progress/share` mencabutnya.                                                          |
| `GET /share/:token`                 | -    | Ringkasan publik progres (nama tampilan, poin, streak, modul selesai); **tanpa email**. Token tidak dikenal → 404.                   |
| `GET /progress/certificate?module=` | ya   | PDF sertifikat bila semua pelajaran dan latihan modul (atau `semua`) selesai; selain itu 409. Kode disimpan di tabel `certificates`. |
| `GET /certificates/:code`           | -    | Verifikasi publik kode sertifikat. Sertifikat ini penanda penyelesaian di Mahir Excel, **bukan** sertifikasi resmi Microsoft.        |

`POST /auth/email/request` dan `/verify` juga menerima `purpose: "verify"` (pengguna login memverifikasi email akunnya); tujuan ini memeriksa CSRF secara manual karena rute email dikecualikan dari CSRF global.

Poin: kunci utama `(user_id, exercise_id)` pada `exercise_completions` + `INSERT IGNORE` dalam transaksi → submit ganda/bersamaan hanya memberi poin sekali. Semua percobaan dicatat di `exercise_attempts`.

## Admin (peran `admin`, diperiksa di backend)

`GET /admin/stats`, `GET /admin/stats/usage` (14 hari: pengunjung, halaman dibuka, pendaftar, percobaan akun dan tanpa akun, halaman populer), `GET /admin/stats/hard` (latihan dengan tingkat gagal tertinggi), `GET /admin/users.csv` dan `GET /admin/stats/usage.csv` (ekspor CSV dengan perlindungan CSV injection), `GET /admin/users?q=&page=&pageSize=` (daftar pengguna dengan ringkasan aktivitas; memuat email) dan CRUD untuk `modules`, `lessons`, `exercises`, `shortcuts`, `worksheets`:

`GET /admin/:resource?page=&pageSize=` · `GET /admin/:resource/:id` · `POST /admin/:resource` · `PUT /admin/:resource/:id` (ganti penuh) · `DELETE /admin/:resource/:id`

- Body divalidasi Zod. Untuk `exercises`, jawaban acuan harus lolos validasinya sendiri (kalau tidak, 400).
- Slug ganda → 409. Menghapus modul yang masih punya pelajaran → 409.
- Setiap perubahan dicatat di `admin_audit_logs`.
- Pengguna biasa → 403, anonim → 401.

## Skema database

Lihat `database/migrations/001_init.sql`. Migrasi 002 menambah kolom `users.last_login_at/email_verified_at/has_password` serta tabel `email_codes`, `daily_stats`, `analytics_salts`, `visitor_hashes`. Migrasi 007 menambah tabel `sprint_sessions` dan `sprint_scores`. Migrasi 006 menambah `users.google_sub` (unik) dan `users.premium_until`. Migrasi 005 menambah tabel `placement_results` (skor tes penempatan; `user_id` boleh kosong). Migrasi 003 menambah `exercises.tools` (JSON; rentang urutkan/filter untuk latihan tertentu). Migrasi 004 menambah `users.share_token`, nilai `verify` pada `email_codes.purpose`, serta tabel `review_schedule` dan `certificates`. Tabel: `users`, `modules`, `lessons`, `exercises`, `lesson_progress`, `exercise_attempts`, `exercise_completions`, `review_items`, `learning_days`, `shortcuts`, `worksheet_resources`, `admin_audit_logs`, `schema_migrations`. Kolom JSON dipakai untuk konten pelajaran, dataset/validasi/petunjuk latihan, serta daftar keterampilan/petunjuk worksheet. Streak dihitung dari `learning_days` (zona waktu Asia/Jakarta), jadi tidak ada tabel `learning_streaks` terpisah; favorit shortcut hanya lokal sehingga tidak ada `user_favorites`.

Retensi data: data akun disimpan selama akun aktif dan dihapus permanen saat pengguna menghapus akunnya (`DELETE /auth/account`). Pengunjung tanpa akun tidak disimpan di server.
